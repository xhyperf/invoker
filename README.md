# xhyperf/invoker

一个基于 Hyperf 框架的策略模式实现和参数自动适配的反射调用组件。

## 功能特点

- 策略模式的优雅实现：通过注解和枚举定义策略，支持作用域区分
- 参数自动适配：智能匹配参数名称和类型，无需手动处理参数映射
- 参数映射注解：支持自定义参数来源映射

## 安装

```bash
composer require xhyperf/invoker
```
